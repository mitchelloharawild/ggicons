# ggicons

The ggicons package allows you to visualise data with icons in ggplot2.
It uses icons from the
[icons](https://pkg.mitchelloharawild.com/ggicons/pkg.mitchelloharawild.com/icons/)
package as the `icon` aesthetic in
[`geom_icon()`](https://pkg.mitchelloharawild.com/ggicons/reference/geom_icon.md).

## Installation

You can install the **development** version from
[GitHub](https://github.com/mitchelloharawild/ggicons)

``` r

# install.packages("remotes")
remotes::install_github("mitchelloharawild/ggicons")
```
